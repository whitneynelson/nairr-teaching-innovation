Connecting to Vista An SSH guide for every platform

How to open a secure connection to Vista (TACC) from Windows, macOS, or Linux — including the fix for the port 22 error many Windows users hit on their first try.

Before you start Windows macOS Linux Password & MFA Troubleshooting Get help

Section 01

Before you start

Confirm all four of these first. A missing allocation or unset MFA is the most common reason a login fails even when the command is correct.

Your checklist

  1. You have a TACC account. If not, create one at tacc.utexas.edu/portal.
  2. You are on the Vista allocation. If your project isn't attached to Vista, your password will be rejected. Check under Projects & Allocations in the TACC Portal.
  3. Multi-Factor Authentication (MFA) is paired. Vista requires it every login. Set it up under Manage Account in the TACC Portal (MFA guide).
  4. You know your TACC username and password, and your phone or authenticator app is within reach.

Everywhere in this guide, replace your_username with your real TACC username. The address you connect to is always the same:

host
vista.tacc.utexas.edu

Section 02

Windows

Connecting from Windows

Windows ships with its own SSH program, but on many campus machines it fails the secure "handshake" with TACC and reports a port 22 error. Think of two people who speak the same language but can't agree on which greeting to use — the conversation never starts. The two tools below bring their own SSH software and connect cleanly on the same computer and network, so this is not a firewall problem on your end.

Use either Git Bash or PuTTY. You only need one.

Option A — Git Bash (recommended)

Git Bash gives you a Linux-style window on Windows, so your steps match the Mac and Linux instructions closely.

  1. Install Git for Windows. Download from git-scm.com/download/win, run the installer, and click Next through the defaults, then Install. The defaults are fine.
  2. Open Git Bash. Click Start, type Git Bash, and open it. A dark window with a blinking cursor appears — that's your command line.
  3. Connect to Vista. Type this and press Enter:
    Git Bash
    $ ssh your_username@vista.tacc.utexas.edu
  4. Accept the security prompt (first time only). You'll see a message about the host's authenticity ending in a yes/no question. Type yes and press Enter. You won't see this again from the same computer.
  5. Enter your password and MFA code. See the Password & MFA section below — the flow is identical on every platform.

To log out, type exit and press Enter.

Option B — PuTTY

PuTTY is a small point-and-click program. Nothing to type until you're already connected.

  1. Install PuTTY. Go to putty.org, open the official download page, and get the 64-bit MSI installer. Run it and accept the defaults.
  2. Configure the connection. Open PuTTY. In Host Name, enter vista.tacc.utexas.edu. Leave Port at 22 and Connection type on SSH.
  3. Save it for next time (optional). Type Vista in Saved Sessions and click Save. Later, just double-click Vista to reload these settings.
  4. Click Open. A terminal window appears. The first time, a PuTTY Security Alert about the host key pops up — click Accept. One-time step per computer.
  5. Log in. At login as: type your TACC username. Then enter your password and MFA code as described in Password & MFA below.

To log out, type exit or close the window.

Prefer PowerShell or Command Prompt?

You can often get past the port 22 error by telling the built-in client which security algorithm to use. Add the -m hmac-sha2-512 flag:

PowerShell
ssh -m hmac-sha2-512 your_username@vista.tacc.utexas.edu

This is a documented TACC workaround. If it still fails, use Git Bash or PuTTY — those remain the most dependable options.

Section 03

macOS

Connecting from a Mac

macOS has a full SSH client built in, so there's nothing to install and no port 22 workaround needed. You'll use the Terminal app.

  1. Open Terminal. Press Cmd + Space to open Spotlight, type Terminal, and press Enter. (It also lives in Applications → Utilities → Terminal.)
  2. Connect to Vista. Type this and press Enter:
    Terminal
    % ssh your_username@vista.tacc.utexas.edu
  3. Accept the security prompt (first time only). Type yes at the authenticity question and press Enter.
  4. Enter your password and MFA code. Follow the Password & MFA section below.

To log out, type exit and press Enter. If you need graphical applications later, connect with ssh -X your_username@vista.tacc.utexas.edu.

Section 04

Linux

Connecting from Linux

Every Linux distribution includes an SSH client. You'll use your terminal application directly.

  1. Open a terminal. On most desktops, press Ctrl + Alt + T, or find Terminal in your applications menu.
  2. Connect to Vista. Type this and press Enter:
    Terminal
    $ ssh your_username@vista.tacc.utexas.edu
  3. Accept the security prompt (first time only). Type yes and press Enter.
  4. Enter your password and MFA code. Follow the Password & MFA section below.

To log out, type exit. For graphical applications, add -X: ssh -X your_username@vista.tacc.utexas.edu.

Section 05

The password & MFA prompt

Once your connection reaches Vista, the login steps are the same on Windows, macOS, and Linux.

  1. Password. At the password prompt, type your TACC portal password and press Enter. Nothing appears on screen as you type — no dots, no stars, no moving cursor. This is normal and intentional; the window is not frozen. Type carefully, then press Enter.
  2. MFA code. At the TACC Token Code prompt, type the 6-digit code from your authenticator app (or the code sent to your phone) and press Enter. Codes refresh every 30 seconds, so enter a fresh one.

You're in when you see the Vista welcome banner and a prompt ending in something like login1$ or login2$. A few quick checks:

Vista — login node
login1$ whoami     # your username
login1$ pwd        # your home directory
login1$ hostname   # which login node you landed on

One important habit

The login nodes are shared by everyone. Don't run heavy computations directly on them — submit work to the queue with Slurm (sbatch) or start an interactive session with idev. See the Vista User Guide for details.

Section 06

Quick troubleshooting

What you see Most likely cause What to do
Port 22 error in PowerShell / Command Prompt Built-in Windows SSH handshake issue Use Git Bash or PuTTY, or add -m hmac-sha2-512
Password prompt seems frozen while typing Nothing wrong — password entry is always invisible Keep typing, then press Enter
"Permission denied" / password rejected Wrong password, or you're not on the Vista allocation Reset your password in the TACC Portal; confirm your project is on Vista
No MFA prompt, or code rejected MFA not paired, or an expired code Set up / re-check MFA under Manage Account; use a fresh 30-second code
Connects, then drops immediately Often an account or allocation status issue Check account status in the TACC Portal; open a ticket if it persists

Need to file a ticket?

Run the connection with verbose output and include what it prints:

verbose
ssh -vvv your_username@vista.tacc.utexas.edu
