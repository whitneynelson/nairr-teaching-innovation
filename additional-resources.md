# Resources

## AI credits for teachers and researchers

NAIRR provides access to compute, cloud, and AI resources for qualifying researchers and educators, independent of this accelerator. See the [NAIRR Pilot website](https://nairrpilot.org) for current programs and how to apply.

## NAIRR ecosystem & research credits

Beyond NAIRR itself, these providers offer free or discounted compute, cloud, and API credits worth exploring for your own research or classroom use.

### Hugging Face

- [Hugging Face Spaces](https://huggingface.co/spaces) — Host demos, research apps, and reproducible ML workflows.
- [Hugging Face ZeroGPU Program](https://huggingface.co/zerogpu) — Free shared GPU access for Spaces.
- [Hugging Face Compute Grants](https://huggingface.co/grants) — Apply for sponsored compute resources for open research projects.
- [Hugging Face for Research](https://huggingface.co/learn/cookbook/en/enterprise_hub_serverless_inference_api) — Research tooling and inference support resources.
- [Hugging Face Academic Hub](https://huggingface.co/learn) — Educational and research-focused learning resources.

### EleutherAI

- [EleutherAI](https://www.eleuther.ai/) — Open-source AI research collective.
- [EleutherAI Discord Community](https://discord.gg/eleutherai) — Main collaboration space for contributors and researchers.
- [EleutherAI GitHub](https://github.com/EleutherAI) — Open models, evaluation tools, and research repositories.
- [The Pile Dataset](https://pile.eleuther.ai/) — Large-scale open training dataset used in research.

### Databricks

- [Databricks Data Intelligence Platform](https://www.databricks.com/)
- [Databricks Free Edition](https://www.databricks.com/learn/free-edition) — Free workspace for experimentation and teaching.
- [Databricks Research and Education Programs](https://www.databricks.com/learn/training/home)
- [Databricks Documentation](https://docs.databricks.com/en/index.html) — Tutorials, notebooks, and platform docs.
- [MLflow](https://mlflow.org/) — Open-source experiment tracking heavily supported by Databricks.
- [Delta Lake](https://delta.io/) — Open lakehouse infrastructure for large-scale research datasets.

### CloudBank

- [CloudBank](https://www.cloudbank.org/) — NSF-supported cloud access brokerage for researchers and educators.
- [CloudBank Allocation Requests](https://www.cloudbank.org/get-started/) — Request cloud credits and support.
- [CloudBank for Educators](https://www.cloudbank.org/education/) — Educational cloud allocation pathways.
- [CloudBank Managed Services](https://www.cloudbank.org/services/) — Multi-cloud budget management and support.
- [CloudBank FAQ](https://www.cloudbank.org/faq/)

CloudBank is especially valuable for NSF-aligned projects needing AWS, Azure, or Google Cloud credits without directly managing institutional billing complexities.

### Anthropic

- [Anthropic External Researcher Access Program](https://support.anthropic.com/en/articles/9125743-what-is-the-external-researcher-access-program) — Free API credits for AI safety/alignment researchers.
- [Anthropic AI for Science Program](https://www.anthropic.com/news/ai-for-science-program) — Scientific research support initiative with API credits.
- [Anthropic API Console](https://console.anthropic.com/) — Access Claude API and workbench tools.
- [Anthropic Developer Docs](https://docs.anthropic.com/)
- [Anthropic Cookbook](https://github.com/anthropics/anthropic-cookbook) — Example workflows and research implementations.

### AWS

- [AWS Cloud Credits for Research](https://aws.amazon.com/grants/) — Main AWS research credit program.
- [AWS Cloud Credit Application Page](https://pages.awscloud.com/aws-cloud-credit-for-research.html) — Direct application portal.
- [AWS Research Initiatives](https://aws.amazon.com/research-initiatives/)
- [AWS Educate](https://aws.amazon.com/education/awseducate/)
- [AWS Open Data Registry](https://registry.opendata.aws/) — Public datasets for large-scale research.
- [Amazon SageMaker Studio Lab](https://studiolab.sagemaker.aws/) — Free GPU notebook environment for researchers/students.
- [AWS Activate](https://aws.amazon.com/startups/credits) — Startup credits that can also support research commercialization.
- [AWS Marketplace for Research](https://aws.amazon.com/marketplace/solutions/research-and-technical-computing/)
