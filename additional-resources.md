## AI, cloud, and research credits

NAIRR provides access to compute, cloud, and AI resources for qualifying researchers and educators, independent of this accelerator. See the [NAIRR Pilot website](https://nairrpilot.org) for current programs and how to apply. Beyond NAIRR itself, these providers offer free or discounted compute, cloud, and API credits worth exploring for your own research or classroom use.

#### Hugging Face

| Resource | Description |
|:---|:---|
| [Spaces](https://huggingface.co/spaces) | Host demos, research apps, and reproducible ML workflows |
| [ZeroGPU Program](https://huggingface.co/zerogpu) | Free shared GPU access for Spaces |
| [Compute Grants](https://huggingface.co/grants) | Sponsored compute for open research projects |
| [Hugging Face for Research](https://huggingface.co/learn/cookbook/en/enterprise_hub_serverless_inference_api) | Research tooling and inference support |
| [Academic Hub](https://huggingface.co/learn) | Educational and research-focused learning resources |

#### EleutherAI

| Resource | Description |
|:---|:---|
| [EleutherAI](https://www.eleuther.ai/) | Open-source AI research collective |

| [GitHub](https://github.com/EleutherAI) | Open models, evaluation tools, and research repositories |
| [The Pile Dataset](https://pile.eleuther.ai/) | Large-scale open training dataset used in research |

#### CloudBank

| Resource | Description |
|:---|:---|
| [CloudBank](https://www.cloudbank.org/) | NSF-supported cloud access brokerage for researchers and educators |
| [Allocation Requests](https://www.cloudbank.org/get-started/) | Request cloud credits and support |
| [For Educators](https://www.cloudbank.org/education/) | Educational cloud allocation pathways |
| [Managed Services](https://www.cloudbank.org/services/) | Multi-cloud budget management and support |
| [FAQ](https://www.cloudbank.org/faq/) | Common questions about CloudBank's services |

CloudBank is especially valuable for NSF-aligned projects needing AWS, Azure, or Google Cloud credits without directly managing institutional billing complexities.
